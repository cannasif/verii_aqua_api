# Aqua paged search contract matrix

Bu belge 19 Ağustos 2026 tarihinde Aqua API ve web kaynaklarından çıkarılan canonical paged sözleşme envanteridir. Reflection tabanlı `PagedEndpointContractTests.CanonicalPagedRouteManifest_CoversEveryPagedAction` testi aşağıdaki 74 `PagedRequest` tabanlı `POST .../paged` route'unu gerçek endpoint tablosuyla birebir karşılaştırır. Eski sayfalı `GET` route'ları kaldırılmıştır; Aqua web listeleri yalnız canonical JSON body ile `POST /paged` kullanır. Hangfire izleme modülündeki dört özel sayfalı route da aynı POST/body kuralına tabidir ve ayrıca sözleşme testiyle doğrulanır.

## Ortak sözleşme ve profil anahtarı

Tüm satırlarda `filters`, `filterLogic`, allowlist kontrollü sort, `CountAsync` sonrası stabil sort ve overflow güvenli `Skip/Take` vardır. Ana sort `Id` değilse `Id` tie-breaker uygulanır. Search yalnız whitespace ile bölünür; terimler AND, seçilen alanlar OR'dur. String search SQL Server'a kolon fonksiyonu uygulanmadan escaped bracket `LIKE` olarak çevrilir. Geçersiz field/operator/value/direction ve limit ihlalleri 400 döner.

- **M** — Servisteki `PagedColumns`/`ColumnMapping` sözlüğü public key'i entity veya projection path'ine açıkça eşler. İç içe client path kabul edilmez.
- **S** — Sade entity/projection endpoint'i için `QueryHelper` yalnız o `T` tipinin top-level scalar property'lerinden kapalı, case-insensitive bir allowlist çıkarır. Navigation/path kabul edilmez. Güvenlidir ancak açık endpoint sözlüğüne dönüştürülmesi kalan teknik borçtur.
- **P** — Projection veya özel predicate profili; public key servis içindeki açık dictionary/predicate ile çözülür.
- **UI-Crud** — `AquaCrudPage` ortak `PageToolbar`, alan tercihi, advanced filter ve tam request query-key akışını kullanır.
- **UI-Custom** — Stock, User, Permission veya Netsis gibi özel ekran aynı canonical factory/toolbar sözleşmesine bağlanmıştır.
- **Lookup** — Bağımsız grid yerine remote paged dropdown/iş akışı tüketicisidir; search doluyken seçili field body'de gider.
- **API** — Kaynakta doğrudan Aqua web liste ekranı bulunmadı.

`Public key -> backend` hücresindeki sözlük adı ilgili service dosyasındaki eksiksiz mapping'in kaynağıdır; `S: scalar(T)` ise public key ile aynı adlı top-level scalar property'nin eşleştiğini belirtir. `Default` hücresi boş request'te aranan sözlük alanlarını veya scalar string/numeric varsayılanını gösterir. `F/S/P` sırasıyla filter/sort/paging desteğini gösterir. Bütün satırlarda schema migration durumu `yok`tur.

## Web sözleşme kapsamı

`AquaCrudPage` kullanan bütün gerçek paged gridler searchable kolon allowlist'inden 1–12 alan seçer, tercihi sayfa bazında temizleyerek saklar ve `search`, `searchFields`, `filters`, `filterLogic`, sort, page ve context'in tamamını request/query key'e bağlar. Özel Stock, User, Permission Group, Permission Definition ve Netsis Mirror ekranları aynı davranışa ayrıca bağlanmıştır. Remote lookup tarafında `useDropdownInfiniteSearch`, combobox ve dropdown API ilk sayfa/sonraki sayfa, `AbortSignal` ve sayfa dışında seçili label çözümünü destekler.

`HangfireMonitoringPage` Aqua `PagedRequest`/SQL business koleksiyonu değildir ve Hangfire'ın kendi cevap modeli üzerinde client-side filtreyi bilinçli olarak korur. Dashboard, quick-entry/setup ve rapor ekranlarındaki kalan `.filter()` kullanımları free-text grid search değildir; seçili proje/kafes kompozisyonu, form uygunluk kuralı veya zaten server'dan gelen rapor sonucunun sunum dönüşümüdür. Bunları generic `/paged` contract'a zorlamak yerine ayrı aggregation/context endpoint'i tasarımı gerekir.

## Coverage sınırı

Reflection testi route eksikliğini ve her GET `PagedRequest` action'ının canonical POST eşini doğrular. Ortak unit/SQL/HTTP testleri pattern, punctuation, selected field, strict 400 ve paging davranışını temsilî endpoint/context üzerinde doğrular. Gerçek SQL verisi olmadan her route × her public field için ID-set eşitliği iddia edilmez; güvenli test ortamı sağlandığında WMS'deki read-only live matrix yaklaşımının Aqua endpoint manifesti üzerinde çalıştırılması önerilir.
